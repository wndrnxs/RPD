# 아트 프롬프트 관리

AI로 생성한 모든 에셋의 프롬프트와 시드를 여기에 기록합니다.

**왜 필요한가:** 6개월 뒤에 "이 타워만 살짝 고치고 싶다"는 일이 반드시 생깁니다.
그때 프롬프트가 없으면 처음부터 다시 만들어야 하고, 스타일이 어긋납니다.

## 규칙

1. 생성할 때마다 **프롬프트 전문 + 시드 + 모델명 + 날짜**를 기록
2. 채택한 것뿐 아니라 **버린 시도도** 남길 것 (같은 실패를 반복하지 않기 위해)
3. 스타일 시트(`00-style-sheet.md`)는 **모든 생성의 기준**. 여기가 흔들리면 전부 흔들립니다
