## 플레이 방법

1. 빈 칸 탭 → 카드 7장
2. 손패에서 5장 탭해서 선택
3. 선택 슬롯을 탭하면 토큰 1개로 교체 (파란 테두리 = 토큰 사용됨, 더는 못 바꿈)
4. 확정 → 족보에 따라 타워 생성
5. 하단 **족보 강화** 패널에서 골드 투자
6. 라운드 시작

## ⚠️ 확인해야 할 것

플레이하시면서 아래를 봐주세요. **이게 이 프로토타입을 만든 이유입니다.**

### 1. ~~건설 템포~~ → 5장 딜로 수정됨
"5장 고르기" 단계가 사라졌습니다. 이제 딜 → 토큰 교체 → 확정.
여전히 느리다면 "빠른 건설" 모드가 필요합니다.

### 2. 족보 강화가 포커 선택을 바꾸는가 ★
투 페어를 Lv.3까지 올린 뒤, **트리플이 가능한 패에서 일부러 투 페어를 만들게 되나요?**
이게 [GDD 3.1절](../docs/01-game-design.md)이 노린 가장 깊은 판단입니다.
안 그렇게 된다면 강화 배수가 부족한 것입니다.

### 3. ~~골드 수지~~ → 재설계됨 (하지만 재검증 필요)
30R 총수입을 14,998G → 6,391G로 낮췄습니다. 이제 **반대 위험**을 봐주세요:

**강화를 처음 사는 게 몇 라운드인가요?** R15 이후라면 너무 조인 것입니다.
"건설 vs 강화"가 선택이 아니라 강제가 되면 전략 축이 죽습니다.

### 4. 한 족보 몰빵이 최적해인가
한 족보만 Lv.5까지 올리는 게 여러 족보를 Lv.2씩 올리는 것보다 강한가요?
→ 그렇다면 레벨당 비용 증가율을 더 키워야 합니다.

### 5. 탑(하이카드)이 나왔을 때
얼마나 짜증나나요? 구제책이 필요한 수준인가요? ([04 C-3](../docs/04-open-questions.md))

## 결과 보내주실 것

게임이 끝나면 통계 화면이 나옵니다. 거기서:

- **도달 라운드**
- **뽑은 족보 분포** — 실제 플레이가 시뮬레이터 예측(탑 27.8% / 원 페어 49.1% / 투 페어 12.1%)과 맞는지
- **골드 수지** — 획득 / 건설 / 강화
- 위 5가지에 대한 체감

이걸 알려주시면 수치를 조정하겠습니다.
