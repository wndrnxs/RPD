## 1. 코어 루프

```
스테이지 진입
  └─ 라운드 시작 전 (준비 페이즈, 제한 없음 / 조기 소환 시 골드 보너스)
       ├─ 빈 슬롯 탭 → 건설 비용 지불 → [포커 페이즈] → 타워 생성
       ├─ 기존 타워 탭 → 전술 강화 구매 (이번 라운드 한정)
       └─ 다음 웨이브 프리뷰 확인 (몬스터 속성/유형)
  └─ 라운드 진행 (몬스터 스폰 → 경로 이동 → 타워 교전)
       └─ 누수 시 라이프 감소
  └─ 라운드 종료
       ├─ 골드 보상 지급
       ├─ 전술 강화 전부 소멸 ★
       └─ 10라운드마다: 미니보스 처치 → 아티팩트 3택 1
  └─ 최종 라운드 = 스테이지 보스 → 처치 시 스테이지 클리어
       └─ 별점 판정 → 캠페인 보상 (캐릭터/장비 조각, 재화)
```

**핵심 긴장감 3가지**

1. **비용 곡선 vs 족보 운** — 타워는 지을수록 비싸지는데 결과물의 강함은 운. "지금 지어야 하나, 골드를 모아야 하나."
2. **전술 강화의 휘발성** — 이번 라운드에 쓸 것인가, 다음 타워 건설비로 저축할 것인가.
3. **속성 상성** — 다음 웨이브의 속성을 보고 어떤 무늬를 노릴지 정하지만, 카드는 마음대로 안 나온다.

## 2. 포커 시스템

### 2.1 건설 플로우 (확정)

| 단계 | 동작 |
|---|---|
| ① | 빈 슬롯 탭 → 건설 비용 확인 → 확정 |
| ② | 셔플된 52장 덱에서 **8장**을 딜 |
| ③ | 플레이어가 그중 **5장**을 선택 (나머지 3장은 폐기) |
| ④ | **리드로우 토큰 3개**를 원하는 대로 사용해 카드를 교체 (토큰 1개 = 카드 1장) |
| ⑤ | 교체 카드는 **아직 공개되지 않은 카드** 중에서만 나옴 — 폐기·교체된 카드는 절대 재출현하지 않음 |
| ⑥ | 최종 5장 확정 → 족보 판정 → 타워 생성 |

**리드로우 토큰 규칙**

- 기본 **3개**. 남은 토큰은 건설이 끝나면 소멸합니다.
- **같은 슬롯을 여러 번** 교체할 수 있습니다 (토큰이 남아있는 한).
- **여러 장을 한 번에** 교체해도 되고(빠름), **한 장씩 순차로** 교체해도 됩니다(결과를 보고 다음을 결정 — 신중).
- 토큰 개수는 캐릭터·장비·아티팩트로 늘어납니다. → **핵심 성장 축**

기타:
- 덱은 **건설할 때마다 새로 셔플**됩니다. (라운드 간 카드 카운팅 부담 없음 — 캐주얼 접근성 유지)
- 취소 불가: ②에서 카드를 본 뒤 물릴 수 없습니다. 비용은 ①에서 이미 지불.

### 2.2 왜 토큰 방식인가

리드로우 설계에는 세 가지 후보가 있었습니다.

| | 1회 일괄 (최대 4장) | 슬롯당 1회 (최대 5장) | **토큰 3개 (채택)** |
|---|---|---|---|
| 같은 슬롯 재시도 | ✗ | ✗ | **○** |
| 순차 판단 (결과 보고 결정) | ✗ | ○ | ○ |
| 성장 축의 깔끔함 | 애매 | 애매 (5→10은 도약이 너무 큼) | **토큰 +1** |
| UI 복잡도 | 낮음 | **가장 낮음** | 낮음 (카운터 1개) |

**토큰을 채택한 이유:**

1. **순차 판단이 실력 요소를 만든다.** 한 장 바꾼 결과를 보고 다음을 결정할 수 있으면 운 게임이 판단 게임이 됩니다.
2. **성장 보상이 룰 변경이 된다.** 장비가 "공격력 +10%"를 주는 것보다 "리드로우 토큰 +1"을 주는 쪽이
   체감이 압도적으로 큽니다. 숫자가 아니라 플레이 방식이 바뀌니까요.
   메타 성장([8절](#8-메타-성장-콜렉션))과 아티팩트([7절](#7-아티팩트))의 사용처가 한 번에 정리됩니다.
3. **같은 슬롯 재도전이 텐션을 만든다.** "이 한 장만 맞으면 플러시" 상황에서 3번 연속 도전 —
   게다가 버려진 카드는 안 나오므로 시도할수록 확률이 조금씩 오릅니다. 포커 게임의 심장부입니다.
4. **난이도 다이얼이 숫자 하나다.** 게임이 너무 쉬우면 토큰을 2개로, 어려우면 4개로.
   룰 설명은 한 줄 그대로입니다.

> **토큰 5개는 너무 강합니다.** 하이카드가 사실상 사라지고 플러시가 흔해져서
> 족보 간 위계가 무너집니다. 기본 3개로 시작해 M0 시뮬레이터로 검증합니다.

### 2.3 족보 확률 — 밸런싱의 출발점 ⚠️

**인터넷의 포커 확률표를 이 게임에 그대로 쓰면 안 됩니다.**

교과서 확률(원페어 42%, 플러시 0.2%)은 **"카드 5장을 그냥 받았을 때"** 의 숫자입니다.
우리 게임은 세 가지가 다릅니다:

1. 5장이 아니라 **8장**을 받는다
2. 그중 **가장 좋은 5장을 고른다**
3. 게다가 **토큰 3개로 바꿀 수 있다**

8장 안에서 같은 무늬 5장을 찾는 건 5장 안에서 찾는 것보다 훨씬 쉽습니다.
그래서 좋은 족보가 교과서보다 **훨씬 자주** 나옵니다.

> 주사위 5개를 굴려 6을 노리는 것과, 8개를 굴려 그중 잘 나온 5개만 골라 쓰는 것의 차이입니다.

| 족보 | 5장 그냥 받기 (교과서) | 7장 중 최선 5장 (홀덤) | **8장 + 토큰3 (추정)** |
|---|---|---|---|
| 하이카드 | 50.1% | 17.4% | ~6% |
| 원페어 | 42.3% | 43.8% | ~35% |
| 투페어 | 4.75% | 23.5% | ~29% |
| 트리플 | 2.11% | 4.83% | ~8% |
| 스트레이트 | 0.39% | 4.62% | ~10% |
| 플러시 | 0.20% | 3.03% | ~8% |
| 풀하우스 | 0.14% | 2.60% | ~4% |
| 포카드 | 0.024% | 0.168% | ~0.5% |
| 스트레이트 플러시 | 0.0014% | 0.031% | ~0.15% |
| 로열 플러시 | 0.00015% | 0.0032% | ~0.02% |

**왜 이 표가 중요한가**

타워 10종의 세기와 몬스터 체력을 정하려면, 각 족보가 실제로 몇 % 나오는지를 먼저 알아야 합니다.

- "플러시는 500판에 한 번 나오니까 엄청 세게 만들자" → 실제로는 **12판에 한 번** 나옵니다. 게임이 무너집니다.
- "하이카드가 나오면 크게 손해보게 하자" → 실제로는 **6%** 밖에 안 나옵니다. 그 장치는 존재감이 없습니다.

**그래서 M0에서 시뮬레이터를 먼저 만듭니다**

위 표의 마지막 열은 전부 **추정치**입니다. 손으로 계산할 수가 없습니다 —
플레이어가 8장 중 무엇을 고를지, 어떤 카드를 몇 번 바꿀지가 전부 변수이기 때문입니다.

그래서 **컴퓨터가 자동으로 10만 번 플레이하게 하고 결과를 세는** 방식을 씁니다.
이걸 몬테카를로 시뮬레이션이라고 부르는데, 어려운 기법이 아니라 말 그대로
"엄청 많이 돌려보고 세는 것"입니다. 코드로는 반나절이면 됩니다.

플레이어 선택 휴리스틱을 2~3종 모델링합니다:
- **초보** — 눈에 보이는 페어만 챙기고 토큰을 다 씀
- **평균** — 페어/무늬 중 기대값이 높은 쪽을 잡고 2장쯤 교체
- **숙련** — 남은 덱 구성까지 계산해 최적 교체

셋의 결과 분포가 나오면, 그 구간 안에서 타워 스탯을 튜닝합니다.

**이 표가 확정되기 전에 타워 스탯을 튜닝하면 전부 다시 해야 합니다.**

**표에서 이미 나오는 설계 결론**

- 밸런스의 무게중심은 **원페어~투페어**입니다. 여기가 "평범한 타워"의 기준선.
- 하이카드는 거의 안 나오므로 "실패 페널티"가 아니라 **드물게 보는 꽝**으로 취급 — 철거 환급을 관대하게.
- 포카드 이상은 **한 스테이지에 한두 번 볼까 말까** → 연출과 임팩트를 아낌없이 줘도 됩니다.
- 스트레이트/플러시가 비슷한 확률대이므로 **동급 파워**로 두되 성격을 다르게 (관통 vs 광역).

### 2.4 카드 → 타워 변환 규칙

최종 5장은 **세 개의 축**으로 읽습니다.

| 축 | 읽는 법 | 결정하는 것 |
|---|---|---|
| **족보** | 10단계 | 타워 종류 · 공격 패턴 · 기본 스탯 |
| **무늬** | 최다 무늬 | 속성 (상성) |
| **숫자** | 랭크 합 · A 개수 | 미세 스탯 보정 |

**속성 결정 규칙**

- 5장 중 **가장 많은 무늬**가 속성이 된다.
- 3장 이상 → **순속성**: 속성 효과 100%
- 정확히 2:2:1 등으로 동수 → 그중 **최고 랭크 카드의 무늬**를 채택하되 속성 효과 **60%** 로 약화
- → 결과적으로 "같은 무늬를 모으는 것"이 족보와 별개로 항상 이득. 플러시 지향 플레이에 보상.

**숫자 보정**

- 랭크 합 S (J=11, Q=12, K=13, A=14). 5장이면 대략 20~60 범위.
- 공격력 배율 = `1 + (S - 35) / 200` → 대략 **±10%**
- A 1장당 치명타 확률 **+4%** (기본 치명타 5%, 배율 ×2.0)

### 2.5 족보 → 타워 매핑

| 족보 | 타워명(가) | 기본 DPS | 사거리(타일) | 공격 패턴 |
|---|---|---|---|---|
| 하이카드 | 감시 초소 | 10 | 2.5 | 단일 대상 |
| 원페어 | 쌍열 포탑 | 18 | 2.5 | 단일, 2연사 |
| 투페어 | 교차 포대 | 26 | 2.5 | 서로 다른 2체 동시 타격 |
| 트리플 | 삼연장포 | 40 | 3.0 | 3연사 버스트 (사이 간격 있음) |
| 스트레이트 | 레일 랜스 | 55 | 4.5 | **직선 관통** (경로를 길게 훑는 위치가 강함) |
| 플러시 | 원소 증폭탑 | 70 | 3.0 | 원형 광역, 속성 효과 **×1.25** 추가 |
| 풀하우스 | 중력 제단 | 95 | 3.5 | 광역 + 이동속도 **-30%** |
| 포카드 | 사방 요새 | 130 | 3.0 | 4방향 동시 연사 |
| 스트레이트 플러시 | 프리즘 랜스 | 180 | 5.0 | 관통 + 관통선상 속성 폭발 |
| 로열 플러시 | 왕좌 | 300 | 전역 | 전역 저격, 비보스 대상 **처형**(HP 15% 이하 즉사) |

> **건설 비용은 족보와 무관하게 동일합니다.** 이게 이 게임의 핵심 도박성입니다.
> 같은 돈을 내고 감시 초소가 나올 수도, 왕좌가 나올 수도 있습니다.

### 2.6 무늬 상성

4무늬 순환 상성. **♠ → ♣ → ♥ → ♦ → ♠** (화살표 = 강함)

| 무늬 | 속성 | 고유 효과 | 강함 | 약함 |
|---|---|---|---|---|
| ♠ 스페이드 | **관통** | 대상 방어력 40% 무시 | ♣ | ♦ |
| ♣ 클로버 | **맹독** | 3초간 최대 HP 2%/초 지속 피해 (보스에게도 유효) | ♥ | ♠ |
| ♥ 하트 | **열화** | 착탄 지점 주변 1타일에 화상 스플래시 | ♦ | ♣ |
| ♦ 다이아 | **서리** | 이동속도 -25%, 피격 취약 +15% (2초) | ♠ | ♥ |

- 유리: **×1.5** / 불리: **×0.7** / 중립: **×1.0**
- 몬스터도 4속성 중 하나를 가지며, **웨이브 프리뷰에 표시**됩니다.
- 순속성이 아닌 경우(2.4 참조) 고유 효과만 60%로 약화되고, 상성 배율은 그대로 적용.

**설계 의도:** 다음 웨이브가 ♥ 위주라면 ♠는 손해, ♦를 노려야 한다.
하지만 카드는 뜻대로 안 나오니 "차선책으로 뭘 지을까"가 매 건설의 판단이 됩니다.

## 3. 타워 · 전투

### 3.1 전술 강화 (라운드 휘발 업그레이드)

라운드 종료 시 **전부 초기화**되는 것이 이 시스템의 정체성입니다.

| 스택 | 비용 | 누적 효과 |
|---|---|---|
| 1 | 25G | 공격력 +25% |
| 2 | 50G | 공격력 +50% |
| 3 | 100G | 공격력 +75%, 사거리 +0.5타일 |

- 타워당 최대 3스택. 라운드 종료 시 스택·비용 모두 리셋.
- **왜 휘발인가:** 영구 강화가 있으면 "한 타워에 몰빵"이 최적해가 되어 포커 요소가 죽습니다.
  휘발이면 매 라운드 "이번 웨이브의 위협에 맞춰 어디에 투자하나"를 다시 계산해야 하고,
  영구적인 전력 증강은 **오직 새 타워 건설**로만 가능해서 비용 곡선이 계속 압박으로 작동합니다.
- 라운드 중에도 구매 가능 (실시간). 위기 대응용.

### 3.2 철거

- 환급: **건설 당시 지불액의 40%**
- **철거해도 건설 카운터 n은 감소하지 않습니다.** (싸게 짓고 팔고 반복하는 어뷰징 차단)
- 용도: 꽝 족보 정리, 슬롯 재배치, 속성 갈아타기

### 3.3 타겟팅

기본 4종 + 타워별 개별 설정 (탭 → 우선순위 토글):
`선두` / `후미` / `최대 체력` / `최근접`
기본값은 `선두`. 관통형(스트레이트 계열)은 `최다 관통`이 추가됩니다.

| 시작 골드 | 200 |
| 시작 라이프 | 20 |
| 건설 비용 | `C(n) = round10(60 × 1.13^(n-1))`, n = 누적 건설 횟수 |
| 라운드 클리어 보상 | `30 + 라운드번호 × 6` |
| 몬스터 처치 | 유형별 3~15G |
| 조기 소환 보너스 | 남은 준비시간 1초당 +2G |
| 누수 페널티 | 일반 -1 라이프 / 보스 -5 라이프 |

**건설 비용 곡선 실측치**

| n | 1 | 3 | 5 | 8 | 10 | 15 | 20 | 25 | 30 |
|---|---|---|---|---|---|---|---|---|---|
| 비용 | 60 | 80 | 100 | 150 | 200 | 360 | 660 | 1220 | 2250 |

→ 한 스테이지에서 현실적으로 짓는 타워는 **20~30개** 선. 이게 15×20 맵의 슬롯 밀도와도 맞습니다.

**조기 소환**은 숙련자용 템포 보상입니다. 준비 페이즈를 무제한으로 두되, 빨리 부르면
돈을 더 주므로 "안전하게 갈까, 밀어붙일까"의 선택이 생깁니다.

## 5. 라운드 · 스테이지 · 캠페인

### 5.1 라운드 구조

- 스테이지마다 라운드 수가 **다릅니다** (15 / 20 / 25 / 30 …). 스테이지 데이터에서 정의.
- **10라운드마다 미니보스** 등장 → 처치 시 **아티팩트 3택 1**
- **최종 라운드는 항상 스테이지 보스** → 처치 시 스테이지 클리어

예시:
- 15라운드 스테이지: R10 미니보스 + 아티팩트 / R15 스테이지 보스
- 30라운드 스테이지: R10, R20 미니보스 + 아티팩트 / R30 스테이지 보스

### 5.2 캠페인 구조

```
월드 1 (4~6 스테이지) → 월드 2 → …
```

- **스테이지 셀렉트 맵**. 클리어한 스테이지는 영구 해금, 재도전 가능.
- 스테이지 실패 = 해당 스테이지만 재시작 (캠페인 진행도 손실 없음).
- 스테이지마다 **고유 컨셉**을 부여합니다:
  - 경로 형태 (단일 / 분기 / 교차 / 순환)
  - 몬스터 속성 편향 (예: "얼어붙은 늪 — ♦ 몬스터 위주" → ♥ 타워를 노려야 함)
  - 기믹 (건설 금지 구역, 라운드 중 이동하는 장애물, 특정 무늬 봉인 등)
- **별점 3개**: ① 클리어 ② 라이프 무손실 ③ 스테이지별 도전 과제
  (예: "타워 15개 이하로 클리어", "플러시 이상 타워 5개 건설")

### 5.3 난이도 곡선 설계 원칙

- 월드 1은 **속성 상성을 가르치는 구간**. 웨이브 속성이 노골적으로 한쪽으로 쏠리게.
- 월드 2부터 **혼합 웨이브** 도입 → 단일 속성 몰빵이 통하지 않게.
- 미니보스는 **직전 라운드들의 위협을 압축한 형태**로 설계 (학습 확인용).
- 몬스터 HP는 라운드에 대해 지수적으로 증가하지만, 플레이어의 전력은
  **선형적(타워 개수)** 으로만 증가하므로 아티팩트/족보 운이 그 갭을 메우는 구조.

## 6. 몬스터 설계

| 유형 | 특징 | 카운터 |
|---|---|---|
| 일반 | 표준 HP/속도 | 아무거나 |
| 장갑 | 방어력 높음, 느림 | ♠ 관통 |
| 신속 | HP 낮음, 매우 빠름 | ♦ 서리, 광역 |
| 군집 | 다수 소환, HP 매우 낮음 | ♥ 열화, 광역 |
| 재생 | 초당 HP 회복 | ♣ 맹독 (지속 피해로 회복 상쇄) |
| 은폐 | 특정 타워만 타격 가능 (탐지 필요) | 탐지 능력 보유 타워 |
| 보스 | HP 매우 높음, 방어력 보유, 고유 패턴 | ♣ 맹독 (%피해) + 복합 |

각 몬스터는 **유형 1개 + 속성 1개**를 가집니다.
→ "장갑 ♦ 몬스터" = ♠로 방어력을 뚫고 싶지만 ♦에게 ♠는 불리(×0.7). 이런 딜레마가 재미의 핵심.

**보스 패턴 예시** (스테이지 컨셉별로 다르게):
- 소환형: 주기적으로 군집 소환
- 무적 페이즈: 특정 구간에서 무적, 그 동안 잡몹 처리 강요
- 봉인: 특정 무늬 타워를 일시 무력화 → 단일 무늬 몰빵 응징
- 가속: HP가 줄수록 이동속도 증가

## 7. 아티팩트

10라운드마다 3택 1. **해당 스테이지 안에서만 유지**되고 스테이지 종료 시 사라집니다.
(캠페인 구조이므로 "런 스코프"가 아니라 "스테이지 스코프")

| 예시 | 효과 | 분류 |
|---|---|---|
| 조커의 미소 | 리드로우 토큰 +1 (영구, 스테이지 내내) | 카드 |
| 표식된 덱 | 딜 8장 중 같은 무늬가 항상 3장 이상 포함 | 카드 |
| 한 장 더 | 딜을 8장 대신 9장 받음 | 카드 |
| 고리대금 | 라운드 보상 +50%, 건설 비용 +10% | 경제 |
| 전당포 | 철거 환급 40% → 100% | 경제 |
| 검소한 설계 | 건설 비용 증가율 1.13 → 1.10 | 경제 |
| 원소 공명 | 순속성 타워의 속성 효과 +40% | 전투 |
| 상성 무시 | 불리 상성 배율 0.7 → 0.95 | 전투 |
| 잔류 마력 | 전술 강화 1스택이 라운드 종료 후에도 유지 | 전투 |
| 도박꾼의 손 | 토큰을 같은 슬롯에 연속 사용 시 2번째부터 소모 없음 (건설당 1회) | 카드 |
| 최후의 보루 | 라이프 0이 될 때 1회 5로 부활 | 생존 |

**설계 원칙:** 아티팩트는 **수치 증폭이 아니라 룰 변경**을 지향합니다.
"공격력 +20%"보다 "리드로우 토큰 +1"이 플레이 방식을 바꾸고 기억에 남습니다.

## 8. 메타 성장 (콜렉션)

캠페인 진행으로 **캐릭터와 장비를 수집**하는 구조입니다.

### 8.1 캐릭터

스테이지 시작 전 1명 선택. **패시브 1개 + 1회용 액티브 1개**.

| 캐릭터(가) | 패시브 | 액티브 |
|---|---|---|
| 딜러 | 딜 8장 → 9장 | 이번 건설의 리드로우 토큰 +2 |
| 은행가 | 시작 골드 +150 | 즉시 라운드 보상 1회분 획득 |
| 도박사 | 건설 시 10% 확률로 족보 1단계 상승 | 이번 건설의 리드로우 토큰 +3 |
| 연금술사 | 순속성 판정 기준 3장 → 2장 | 타워 1기의 속성을 원하는 무늬로 변경 |
| 수호자 | 시작 라이프 +10 | 다음 라운드 누수 피해 무효 |

### 8.2 장비

3슬롯: **무기 / 방어구 / 장신구**

| 슬롯 | 영향 축 | 예시 |
|---|---|---|
| 무기 | 타워 전투력 | "예리한 카드 — 치명타 확률 +5%" |
| 방어구 | 생존 | "성벽 문장 — 시작 라이프 +5" |
| 장신구 | 경제 · 카드 | "행운의 동전 — 라운드 보상 +15%" |

- 등급 (일반 / 희귀 / 영웅 / 전설), 중복 획득 시 **강화 재료**로 전환
- 획득처: 스테이지 첫 클리어 보상, 별점 누적 보상, 챕터 클리어 보상

### 8.3 성장 밸런스 원칙 ⚠️

콜렉션 성장은 **어려운 스테이지를 뚫는 수단**이 되어야 하지,
**성장 없이는 못 깨는 벽**이 되면 안 됩니다.

- 모든 스테이지는 **기본 캐릭터 + 장비 없음 + 토큰 3개**로 클리어 가능하도록 설계 (별 1개 기준)
- 콜렉션은 **별 2~3개 조건**과 후반 월드의 여유분을 담당
- 이 원칙은 수익 모델과 직결됩니다. 이걸 어기는 순간
  "돈을 써야 깰 수 있는 게임"이 되고, 포커의 재미도 스토어 평점도 같이 죽습니다.

**성장은 숫자가 아니라 룰로 준다**

| 나쁜 성장 | 좋은 성장 |
|---|---|
| 타워 공격력 +10% | **리드로우 토큰 +1** |
| 시작 골드 +5% | 딜 8장 → 9장 |
| 라이프 +2 | 순속성 판정 3장 → 2장 |

토큰 +1은 체감이 즉각적이고, 플레이 방식 자체를 바꾸며, "얼마나 강해졌는지"가
숫자가 아니라 **선택지의 개수**로 나타납니다. 성장 보상의 기본 화폐로 삼습니다.
다만 토큰은 상한이 필요합니다 — **최대 6개**를 넘기면 족보 위계가 무너집니다.

---

### 8.4 수익 모델과 재화 구조

**모델: 가챠 없는 F2P (모바일) + 프리미엄 (Steam)**

F2P(Free to Play)는 무료로 받아서 게임 안에서 결제하는 방식,
프리미엄은 한 번 사고 추가 결제가 없는 방식입니다. 두 시장의 기대치가 정반대라 이원화합니다.

| | 모바일 (Android/iOS) | Steam |
|---|---|---|
| 가격 | 무료 | $9.99~14.99 |
| 재화 구매 | ○ | ✗ |
| 성장 패스 | ○ (판매) | **기본 포함** |
| 광고 | 선택적 리워드 광고만 | 없음 |
| 콘텐츠 | 동일 | 동일 |

#### 재화 3종

| 재화 | 획득 | 사용처 | 구매 가능 |
|---|---|---|---|
| **골드** | 전투 중 (몬스터 처치, 라운드 보상) | 타워 건설, 전술 강화 | **절대 불가** ★ |
| **코인** | 스테이지 클리어, 별점, 일일 과제 | 장비 강화, 캐릭터 해금 | ○ |
| **보석** | 소량 무료 지급 + 구매 | 코인 교환, 패스 구매, 편의 기능 해금 | ○ |

> ★ **골드(전투 내 재화)는 절대 판매하지 않습니다.** 전투 중에 돈을 사서 타워를 더 지을 수 있으면
> 그 순간 게임의 모든 긴장감이 사라집니다. 이 게임의 재미는 "제한된 골드로 무엇을 지을까"이고,
> 그 제한을 파는 건 재미 자체를 파는 것입니다. 이건 타협 불가 원칙입니다.

#### 판매 상품

| 상품 | 형태 | 비고 |
|---|---|---|
| **영구 성장 패스** | 1회 구매, 캠페인 진행에 따라 보상 지급 | ⭐ 주력 상품 |
| 코인 팩 | 소모성 | 장비 강화용 |
| 캐릭터 개별 구매 | 영구 | **가챠 아님. 원하는 캐릭터를 직접 삽니다** |
| 광고 제거 | 영구 | |
| 편의 기능 팩 | 영구 | 4배속 해금, 자동 최선 족보 버튼, 로드아웃 프리셋 |

#### 왜 시즌 패스가 아니라 영구 패스인가 ⚠️

**1인 개발자는 시즌 패스를 운영할 수 없습니다.**
시즌 패스는 4~8주마다 새 보상 세트, 새 과제, 새 콘텐츠를 계속 공급해야 합니다.
혼자서는 그 속도를 유지할 수 없고, 한 번 시즌이 밀리기 시작하면 유저 신뢰가 무너집니다.

**영구 성장 패스**는 다릅니다:
- 캠페인 진행도(별점 총합)에 따라 보상이 자동으로 풀립니다
- 한 번 만들어두면 **운영 부담이 0**입니다
- 유저 입장에서도 "기간 내에 못 깨면 손해"라는 압박이 없어 평판이 좋습니다
- 나중에 여유가 생기면 시즌제를 추가로 얹을 수 있습니다 (반대 방향은 불가능)

#### 하지 않을 것

| 항목 | 이유 |
|---|---|
| **스태미나 / 플레이 횟수 제한** | 한 판 10분짜리 게임에서 "그만하세요"는 재미가 붙은 순간 유저를 쫓아냅니다. 이탈률이 크게 오르고 Steam에서는 사실상 불가능합니다 |
| **가챠** | 이 게임은 이미 포커라는 랜덤이 핵심입니다. 여기에 가챠를 얹으면 플레이어가 "운이 나빠 진 건지 과금이 부족해 진 건지" 구분할 수 없게 됩니다 |
| **골드 판매** | 위 ★ 참조 |
| **전투 중 부활 결제** | 실패의 무게가 사라지면 스테이지 설계가 의미를 잃습니다 |

#### 구현 시 주의

- 밸런스 데이터에 `monetization_profile` 플래그를 두고 **모바일/Steam 두 프로파일**을 분리합니다.
  Steam 빌드는 진입 시점부터 패스 보상이 전부 해금된 상태로 시작합니다.
- IAP는 Google Play Billing / StoreKit 양쪽 구현이 필요합니다. Godot에서는 플러그인 의존이라
  **일정에 여유를 둬야 합니다**([03 로드맵](03-roadmap.md) M7 참조).
- 구매 복원(Restore Purchases)은 iOS 심사 필수 항목입니다. 빼먹으면 반려됩니다.

**필수 UX 요소:**
- **실시간 족보 미리보기** — 5장을 고르는 동안 현재 조합의 족보/속성/예상 스탯을 계속 표시.
  포커 룰을 모르는 유저도 플레이할 수 있게 하는 가장 중요한 장치입니다.
- **추천 하이라이트** — "이 5장을 고르면 최선의 족보" 를 옵션으로 표시 (초보자 모드)
- 카드 부채꼴 배치는 세로 화면에서 탭 정확도가 떨어지므로 **2행 4열 그리드** 사용
- 리드로우 단계: 선택된 5장 각각에 🔄 버튼. 누르면 토큰 1개 소모 후 **즉시** 새 카드가 뒤집힙니다
- 여러 장을 지목한 뒤 한 번에 뽑는 **일괄 모드** 토글 제공 (숙련자용, 탭 수 절감)
- 토큰 잔량은 ● ● ○ 형태로 상시 표시. 0개가 되면 [확정]만 남습니다
- 이미 폐기된 카드는 화면 구석에 작게 쌓아 보여줍니다 — "저 카드는 안 나온다"는 정보가 판단 근거가 됩니다

### 9.3 모바일 필수 사항

- **배속 1× / 2× / 3×** — 타워 디펜스의 생명. 라운드 중 언제든 전환.
- **일시정지 중에도 건설/강화 가능** — 세로 한손 조작에서 실시간 강요는 스트레스.
- **햅틱** — 건설 확정, 족보 등급별 차등 진동(포카드 이상은 강하게), 누수 경고
- **오프라인 완전 동작** — 네트워크 없이 캠페인 전체 플레이 가능
- **세션 길이** — 한 스테이지 15라운드 ≈ 8~12분 (2× 배속 기준). 출퇴근길 한 판.

## 10. 아트 · 사운드 방향

**전제: 1인 개발 + AI 생성 아트.** 이 제약이 스타일 선택을 좌우합니다.
실무 파이프라인은 [02-tech-architecture.md 9절](02-tech-architecture.md)에 별도로 정리했습니다.

### 10.1 스타일 방향

- **카드는 진짜 카드처럼.** 포커 게임의 촉감(셔플, 딜, 뒤집기, 슬라이드)에 가장 많은 애니메이션 예산을 씁니다.
  카드를 뒤집는 순간이 이 게임의 도파민 지점입니다.
  표준 포커 덱은 퍼블릭 도메인 벡터 에셋이 많아 **AI를 쓸 필요가 없습니다.**
- **타워는 실루엣으로 구분.** 48px 타일 위에서 10종이 한눈에 구분되어야 합니다.
  색은 속성(4색)이 이미 쓰고 있으므로, 종류는 **반드시 형태로** 구분해야 합니다.
  → 채색 전에 **흑백 실루엣 10종을 먼저 확정**하고, 축소해서 구분되는지 검증합니다.
- **속성 4색**은 무늬 색과 직결: ♠ 보라/은 · ♣ 초록 · ♥ 적색 · ♦ 청색.
  색약 대응으로 무늬 아이콘을 항상 병기합니다.
- 배경·UI 프레임·몬스터 일러스트는 AI가 잘하는 영역이라 여기에 시각적 밀도를 몰아줍니다.

### 10.2 사운드

- 족보 확정 시 **등급별 스팅어**. 포카드 이상은 시간 정지 + 전용 연출.
- 카드 뒤집는 소리, 토큰 소모 소리를 정성껏. 이 게임에서 가장 자주 듣게 될 소리입니다.
- BGM은 라이선스 에셋 구매를 권장합니다 — AI 생성 음악은 스토어 정책 리스크가 이미지보다 큽니다.
