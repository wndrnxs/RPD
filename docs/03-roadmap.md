# 03 · 개발 로드맵

기간은 **1인 개발(파트타임 아님, 집중 기준)** 가정입니다. 인원과 아트 조달 방식에 따라 크게 달라집니다.
각 마일스톤은 **"무엇이 되면 끝인가"** 를 명확히 정의해서, 다음 단계로 넘어갈지 판단할 수 있게 했습니다.

---

## M0 · 기반 다지기 (약 1주)

**목표: 밸런싱의 근거를 먼저 확보한다.**

| 산출물 | 설명 |
|---|---|
| Godot 프로젝트 스캐폴딩 | 폴더 구조, autoload, 익스포트 프리셋 초안, .gitignore |
| `core/poker/` | Card, Deck, HandEvaluator |
| `tests/test_hand_evaluator.gd` | 10족보 전수 케이스 + 경계 케이스(A-2-3-4-5 스트레이트, 휠, 동족보 비교) |
| `tests/test_deck_exclusion.gd` | "폐기된 8장이 리드로우에 절대 안 나온다" 검증 |
| **`core/sim/HandSimulator.gd`** ★ | 몬테카를로 10만 회. 플레이어 선택 휴리스틱 2~3종 모델링 |
| `docs/balance/hand-distribution.md` | 시뮬레이터 실측 결과 |

**완료 조건**
- 족보 판정 테스트 100% 통과
- **8장→5장→리드로우 룰의 실제 족보 분포가 숫자로 나온다**

> 이 단계를 건너뛰면 안 됩니다. GDD 2.3의 확률은 전부 추정치이고,
> 타워 스탯·비용 곡선·몬스터 HP가 전부 이 분포 위에 얹힙니다.
> 여기가 틀리면 M2 이후 밸런싱을 통째로 다시 해야 합니다.

## M1 · 수직 슬라이스 (약 2주)

**목표: "재미있는가?"를 판정할 수 있는 최소 플레이어블.**

| 산출물 | 설명 |
|---|---|
| Board / Tile / 고정 경로 | 15×20 그리드, 경로 렌더, 슬롯 탭 |
| 건설 플로우 전체 | 비용 지불 → 8장 딜 → 5장 선택 → 리드로우 → 타워 생성 |
| BuildSheet UI | 2행 4열 손패, **실시간 족보 미리보기**, 리드로우 지목 |
| 타워 3종만 | 하이카드 / 원페어 / 투페어 (단일 대상, 속성 없음) |
| 몬스터 1종, 웨이브 5라운드 | |
| 라운드 컨트롤러 | 준비 → 진행 → 종료, 골드 보상 |

**완료 조건**
- 5라운드짜리 스테이지를 처음부터 끝까지 플레이할 수 있다
- **본인이 플레이해보고 "카드 뽑는 게 재밌다"고 느껴진다**

> **여기가 최대 의사결정 지점입니다.** 재미없으면 룰을 바꿔야 합니다.
> (리드로우 횟수, 딜 매수, 비용 곡선 등) 아트나 콘텐츠에 투자하기 전에 판단하세요.

## M7 · 출시 준비 (약 2주 + 심사 대기)

| 플랫폼 | 작업 |
|---|---|
| **Android** | AAB 빌드, 서명, 스토어 등록정보, 스크린샷, 개인정보처리방침, 내부 테스트 → 비공개 → 프로덕션 |
| **iOS** | macOS+Xcode 빌드, App Store Connect, TestFlight, 심사 (반려 대응 시간 여유 필요) |
| **Steam** | 파트너 등록, 스토어 페이지(출시 2주 전 공개 권장), 가로 레이아웃/키보드·패드 입력, Steam Deck 검증, 빌드 업로드 |

**추천 출시 순서: Android 내부테스트 → Steam 데모/얼리액세스 → iOS**
안드로이드가 반복 배포가 가장 빠르고, Steam은 위시리스트를 미리 쌓을 수 있으며,
iOS는 심사가 가장 까다로워 마지막에 두는 게 리스크가 낮습니다.

## 전체 일정 요약

| 마일스톤 | 기간 | 누적 |
|---|---|---|
| M0 기반 | 1주 | 1주 |
| M1 수직 슬라이스 | 2주 | 3주 |
| M2 전투 완성 | 2주 | 5주 |
| M3 스테이지 구조 | 1.5주 | 6.5주 |
| M4 캠페인+메타 | 2주 | 8.5주 |
| M5 콘텐츠+밸런싱 | 3주 | 11.5주 |
| M6 폴리시 | 2주 | 13.5주 |
| M7 출시 준비 | 2주+ | **약 15.5주 (~4개월)** |

**이 일정의 전제와 위험**
- 아트/사운드를 **에셋 구매 또는 외주**로 조달한다고 가정. 직접 그리면 +4~8주.
- 1인 집중 개발 기준. 파트타임이면 실제 소요는 2~3배.
- M1 이후 "재미없음" 판정이 나면 M1로 되돌아가는 루프가 발생할 수 있습니다. 이건 실패가 아니라 정상입니다.
- 스토어 심사 대기(특히 iOS 초회)는 일정에 포함되지 않았습니다.

**만약 일정을 줄여야 한다면 자르는 순서**
1. 월드 2 (M5) → 출시 후 업데이트
2. 장비 시스템 (M4) → 캐릭터만 먼저
3. iOS (M7) → Android + Steam 먼저
4. 아티팩트 종류 수 (M3) → 6종으로 축소

**절대 자르면 안 되는 것**
- M0 시뮬레이터 (밸런싱 근거)
- 실시간 족보 미리보기 (M1) — 이게 없으면 포커를 모르는 유저를 다 잃습니다
- 배속 기능 (M2) — 타워 디펜스에서 배속은 편의 기능이 아니라 필수 기능입니다
