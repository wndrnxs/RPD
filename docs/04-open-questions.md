# 04 · 미결정 사항

M0 착수 전에 답이 필요한 것과, 나중에 정해도 되는 것을 나눴습니다.

---

## A. M0 전에 정해야 하는 것

### A-1. 수익 모델 ⭐ 가장 중요

메타 성장(캐릭터/장비)의 설계와 밸런스 전체가 여기서 갈립니다.

| 선택지 | 영향 |
|---|---|
| **프리미엄 (유료 1회)** | 모바일 ₩5,000~9,000 / Steam $9.99~14.99. 콜렉션을 순수 재미 요소로 설계 가능. 밸런싱이 가장 깔끔. 대신 모바일 유입이 어려움 |
| **광고 기반 F2P** | 무료 + 배속/재도전/리롤에 리워드 광고. 밸런스는 프리미엄에 가깝게 유지 가능. Steam 버전은 광고 제거 유료판 |
| **F2P + 가챠** | 캐릭터/장비를 가챠로. 매출 상한이 가장 높지만 **콜렉션을 의도적으로 부족하게** 만들어야 해서 GDD 8.3 원칙("성장 없이도 클리어 가능")과 충돌. 스팀 출시와도 궁합이 나쁨 |

> **제 추천: 프리미엄 또는 광고 기반 F2P.**
> 모바일과 스팀 동시 출시를 원하시면 가챠는 두 시장의 기대치가 정면충돌합니다.
> 특히 이 게임은 **이미 포커라는 랜덤 요소가 핵심 재미**인데, 여기에 가챠 랜덤까지 얹으면
> 플레이어가 "운 때문에 진 건지 과금이 부족해서 진 건지" 구분할 수 없게 됩니다.

### A-2. 아트 에셋 조달 방식

일정에 4~8주 차이를 만드는 항목입니다.

- 에셋 스토어 구매 + 조합 (가장 빠름, 개성 약함)
- 외주 (비용 발생, 품질 확보)
- 직접 제작 (일정 크게 증가)
- AI 생성 후 다듬기 (스토어 정책·라이선스 확인 필요)

카드 UI는 표준 포커 덱 디자인을 쓸 수 있어 부담이 적고, **타워 10종의 실루엣 구분**이
가장 어려운 부분입니다.

### A-3. 개발 인원

1인인지, 아트/사운드 담당이 따로 있는지에 따라 M5~M6 일정이 완전히 달라집니다.

### A-4. 게임 제목

저장소 이름을 살려 **RPD = Royal Poker Defense**를 가제로 썼습니다.
스토어 검색 노출과 상표 충돌을 고려해 확정이 필요합니다.

## B. M1~M2에서 플레이테스트로 정할 것

### B-1. 건설 1회에 걸리는 시간

카드 8장을 보고 5장 고르고 리드로우까지 하면 **숙련자도 10~15초**입니다.
한 스테이지에 25개를 지으면 카드 고르기에만 5분 이상 씁니다.

→ **완화책 후보** (M1에서 실측 후 결정):
- "최선의 족보로 자동 선택" 원탭 버튼 (선택만 자동, 리드로우는 수동)
- 리드로우까지 자동으로 하는 "빠른 건설" 모드
- 딜 매수를 8장에서 6~7장으로 줄이기

### B-2. 하이카드가 나왔을 때의 구제책

확률상 8% 정도지만, 비싼 타워를 짓고 하이카드가 나오면 좌절이 큽니다.

→ 후보: 하이카드 시 건설 비용 일부 환급 / 하이카드는 무료 리드로우 1회 추가 /
   하이카드 타워는 철거 환급 100%

### B-3. 덱 스코프

현재 설계는 **건설할 때마다 52장 새 덱**입니다. 대안:

- 라운드 단위 공유 덱 (라운드 안에서 카드 카운팅 성립)
- 스테이지 단위 공유 덱 (가장 깊지만 학습 비용 큼)

M1에서 새 덱 방식으로 만들고, 재미가 부족하면 아티팩트로 "공유 덱" 옵션을 추가하는 방식을 추천합니다.

### B-4. 전술 강화 3스택이 적정한가

휘발이므로 스택이 적으면 존재감이 없고, 많으면 골드가 전부 강화로 흘러가 건설 압박이 사라집니다.

## C. 나중에 정해도 되는 것

| 항목 | 비고 |
|---|---|
| 온라인 기능 | 리더보드, 클라우드 세이브, 일일 챌린지(시드 고정). 결정론적 RNG를 넣어두면 나중에 쉽게 추가 가능 |

| 스테이지 에디터 / 커스텀 맵 | Steam 워크샵 |

## D. 확인 부탁드리는 설계 판단

제가 임의로 정한 것들 중, 원안과 다르거나 의견이 갈릴 수 있는 부분입니다.

| # | 제가 정한 것 | 이유 | 바꾸실 수 있음 |
|---|---|---|---|
| 1 | 맵 30×30 → **15×20** | 30×30이면 타일이 24px(약 3.5mm)라 세로 화면에서 탭이 불가능 | 가로 화면으로 가면 20×14도 가능 |
| 2 | **건설 비용은 족보와 무관하게 동일** | 이게 이 게임의 도박성 그 자체. 족보별로 비용이 다르면 포커가 아니라 그냥 상점이 됨 | |
| 3 | 스테이지 클리어 시 **아티팩트 소멸** | 캠페인 구조라 스테이지가 독립적. 이월되면 후반 스테이지 밸런싱이 불가능 | |
| 4 | **철거해도 건설 카운터 감소 안 함** | 싸게 짓고 팔기 반복하는 어뷰징 차단 | |
| 5 | 무늬 상성을 **4순환** (♠→♣→♥→♦→♠) | 각 무늬가 정확히 하나에 강하고 하나에 약해 대칭적. 상성표 암기 부담 최소 | |
| 6 | **순속성(3장 이상) 개념 도입** | 족보와 별개로 "같은 무늬 모으기"에 항상 보상을 줘서 플러시 지향 플레이를 유도 | |
| 7 | 영구 강화 없음, **전술 강화만 휘발** | 영구 강화가 있으면 한 타워 몰빵이 최적해가 되어 포커 요소가 죽음 | |
| 8 | 준비 페이즈 **시간 제한 없음** + 조기 소환 보너스 | 세로 한손 조작에서 시간 압박은 스트레스. 대신 빨리 부르면 보상 | |
