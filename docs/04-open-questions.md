## B. 아직 정해야 하는 것

### B-1. 게임 제목

저장소 이름을 살려 **RPD = Royal Poker Defense**를 가제로 쓰고 있습니다.
확정 전 확인 사항:

- 스토어 검색 시 유사 제목과 충돌하는지
- 상표 등록 여부
- 영문 제목이 한국 유저에게 발음/기억이 되는지
- 한국어 부제를 병기할지

### B-2. 아트 스타일 방향 (M2 전까지 필요)

AI 생성이므로 **스타일 시트를 먼저 고정**해야 합니다. 후보 방향:

| 방향 | 장점 | 단점 |
|---|---|---|
| 다크 판타지 / 고딕 | 카드·도박 테마와 궁합 좋음, AI가 잘 만듦 | 모바일 스토어 썸네일에서 어두워 눈에 안 띔 |
| 카툰 / 팝 | 스토어 노출에 유리, 캐주얼 유입 | 48px 실루엣 구분이 어려움 |
| 미니멀 / 플랫 벡터 | **일관성 확보가 가장 쉬움**, AI 의존 최소 | 개성이 약함 |
| 픽셀아트 | 48px 타일과 궁합 완벽, 용량 작음 | AI가 가장 못하는 영역 (수작업 필요) |

> 1인 + AI 조건에서는 **미니멀/플랫 벡터 또는 카툰**이 가장 안전합니다.
> 픽셀아트는 결과물은 좋지만 AI로 만들 수 없어 일정을 크게 늘립니다.

### B-3. 가격 책정 (M7 전까지)

- Steam 단품: $9.99 / $12.99 / $14.99 중
- 모바일 성장 패스: ₩5,900 / ₩9,900 중
- 코인·보석 팩 구간

### B-4. 사업자 · 세금 처리

혼자 상업 출시를 하려면 실무가 따라옵니다. **일정에 잡히지 않지만 반드시 걸리는 항목**입니다.

- 개인 vs 개인사업자 vs 법인
- Google Play 개발자 등록 ($25 1회), Apple Developer ($99/년), Steamworks ($100/작품)

- 개인정보처리방침 (스토어 필수)

## C. M1~M2 플레이테스트로 정할 것

### C-1. 기본 리드로우 토큰 개수

3개로 시작하되 M0 시뮬레이터 실측으로 확정합니다.
기준: **하이카드가 5~10% 구간**에 들어오는 값.
2개면 좌절이 잦고, 5개면 족보 위계가 무너집니다.

### C-2. 건설 1회에 걸리는 시간

카드 8장을 보고 5장 고르고 토큰까지 쓰면 **숙련자도 10~15초**입니다.
한 스테이지에 25개를 지으면 카드 고르기에만 5분 이상 씁니다.

→ 완화책 후보 (M1에서 실측 후 결정):
- "최선의 족보로 자동 선택" 원탭 버튼 (선택만 자동, 토큰은 수동)
- 토큰까지 자동으로 쓰는 "빠른 건설" 모드
- 딜 매수를 8장에서 6~7장으로 축소

### C-3. 하이카드가 나왔을 때의 구제책

확률상 6% 정도지만, 비싼 타워를 짓고 하이카드가 나오면 좌절이 큽니다.

→ 후보: 하이카드 시 건설 비용 일부 환급 / 무료 토큰 1개 추가 / 철거 환급 100%

### C-4. 덱 스코프

현재 설계는 **건설할 때마다 52장 새 덱**입니다. 대안: 라운드 단위 공유 덱 / 스테이지 단위 공유 덱.
M1은 새 덱으로 만들고, 깊이가 부족하면 아티팩트로 "공유 덱" 옵션을 추가하는 방향을 추천합니다.

### C-5. 전술 강화 3스택이 적정한가

휘발이므로 스택이 적으면 존재감이 없고, 많으면 골드가 전부 강화로 흘러 건설 압박이 사라집니다.

### C-6. 무과금 재화 획득 속도

무과금 유저가 장비 1세트를 완성하는 데 걸리는 시간.
너무 빠르면 결제 이유가 없고, 너무 느리면 이탈합니다.
M4 완료 조건에 "30~40시간" 기준을 넣어두었으나 실측 필요합니다.

## E. 제가 임의로 정한 설계 판단

원안과 다르거나 의견이 갈릴 수 있는 부분입니다. **동의 안 되시면 말씀해 주세요.**

| # | 제가 정한 것 | 이유 |
|---|---|---|
| 1 | 맵 30×30 → **15×20** | 30×30이면 타일이 24px(약 3.5mm)라 세로 화면에서 탭이 불가능 |
| 2 | 리드로우 "슬롯당 1회" → **토큰 3개** | 같은 슬롯 재도전이 가능해지고, "토큰 +1"이 성장 보상의 기본 화폐가 됨 |
| 3 | **건설 비용은 족보와 무관하게 동일** | 이게 이 게임의 도박성 그 자체. 족보별로 비용이 다르면 포커가 아니라 상점이 됨 |
| 4 | 스테이지 클리어 시 **아티팩트 소멸** | 캠페인 구조라 스테이지가 독립적. 이월되면 후반 밸런싱이 불가능 |
| 5 | **철거해도 건설 카운터 감소 안 함** | 싸게 짓고 팔기 반복 어뷰징 차단 |
| 6 | 무늬 상성 **4순환** (♠→♣→♥→♦→♠) | 각 무늬가 정확히 하나에 강하고 하나에 약해 대칭적. 암기 부담 최소 |
| 7 | **순속성(3장 이상) 개념** | 족보와 별개로 "같은 무늬 모으기"에 항상 보상 → 플러시 지향 유도 |
| 8 | 영구 강화 없음, **전술 강화만 휘발** | 영구 강화가 있으면 한 타워 몰빵이 최적해가 되어 포커 요소가 죽음 |
| 9 | 준비 페이즈 **시간 제한 없음** + 조기 소환 보너스 | 세로 한손 조작에서 시간 압박은 스트레스. 대신 빨리 부르면 보상 |
| 10 | 성장 보상을 **숫자가 아니라 룰 변경**으로 | "공격력 +10%"보다 "토큰 +1"이 체감이 크고 플레이 방식을 바꿈 |
| 11 | **모바일 F2P / Steam 프리미엄 이원화** | 두 시장의 기대치가 정반대. 같은 모델로 양쪽에 내면 한쪽은 반드시 실패 |
| 12 | 타워 스프라이트 **무채색 + 셰이더 틴트** | 10종 × 4속성 = 40장을 10장으로 축소. AI 일관성 문제의 최대 위험 지점을 제거 |
